# ベンチプレス プログラムメーカー

ベンチプレスのMAXを入れるだけで、ベンチプレス専用の4〜12週間プログラムを作る Web ツールです。公開先は https://yuno-lab.com/bench-program/ です。

- 目的（MAXを伸ばす・胸を大きくする・両方）、レベル、週1〜4回、期間、苦手なところ、場所を選べる
- 毎回の重さは、ベンチプレスで何%なら何回できるかの研究の表（Nuzzo 2024）から、回数と余力をもとに決める
- ウォームアップ、片側のプレート、補助種目、最後の週のMAX測定か回数チェックを出す
- 「やった」のチェックと入力内容は、ブラウザ内だけに保存し、サーバーには送信しない

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 入力フォーム・プログラム・決め方と根拠・よくある質問・免責 |
| `tests.html` | ロジックのテスト。ベンチプレス伸び計算機の `js/bg-data.js` と `js/bg-calc.js` も読み込み、数字が一致するか確かめる |
| `js/bp-data.js` | レベル、目的ごとの段階、種目、回数と重さの表などの設定値 |
| `js/bp-program.js` | プログラム作成のロジック |
| `js/app.js` | フォーム・描画・保存・共有リンク・実施チェック |

根拠の研究は、[ベンチプレスの研究まとめ](https://yuno-lab.com/bench-goal/evidence.html)にリンクしています。設定を変えたら `tests.html` を開き、テストがすべて通ることを確認してください。
